# vidThumbClipper

本機端的影片縮圖擷取與剪輯工具，用 Tauri + Vue 3 + TypeScript 打造，剪輯／合併都是呼叫本機的 ffmpeg／ffprobe 執行，影片檔案不會上傳到任何地方。

## 使用前準備

- 需要自行安裝 [ffmpeg](https://ffmpeg.org/) 與 ffprobe，並在「設定」頁面指定執行檔路徑（留空則會嘗試從系統 PATH 尋找）。
- 支援 Windows；Windows 上會自動隱藏 ffmpeg 執行時彈出的主控台視窗。

## 功能總覽

App 分成三個主要頁面：**影片擷取與剪輯**、**影片處理任務**、**設定**，頂部導覽列右側還有一個**視窗置頂**按鈕。

---

### 一、影片擷取與剪輯

這個頁面左側是操作面板，右側是縮圖預覽區，左側面板依「載入影片 / 建立任務 / 合併影片」三個分頁切換。

#### 1. 載入影片

- **選擇影片**：用檔案選擇器載入單一影片作為工作對象；也可以**直接把影片檔案拖曳到視窗中**載入。
- **預先處理（可多選）**：一次選取多支影片，加入「影片處理任務」佇列，用 `ffmpeg -c copy` 重新封裝（remux）成 mp4。用途：修正部分長時間錄影（尤其是直播錄影）常見的時間戳記／索引異常問題，讓後續擷取縮圖時的時間定位更準確。處理完成的影片會列在「已處理影片」清單中，可以直接「使用」載入、單筆移除、或整批清除。
  - 拖曳載入時，一次拖 1 個檔案 = 直接載入為工作影片；拖 2 個以上 = 自動加入預先處理佇列。
- **建立初始縮圖**：指定欄（N）× 列（M），依影片長度平均分布擷取縮圖，建立完成後右側會顯示整個縮圖 grid（含起點、終點兩張實際截圖）。目前的欄列設定會被記住，下次建立新影片的縮圖時自動帶入。
- **擴充兩張縮圖之間**：選取任兩張相鄰縮圖，在中間插入更多縮圖，方便進一步鎖定精確時間點。三種模式：
  - **固定秒數**：以固定間隔（1 / 10 / 60 / 300 秒或手動輸入）插入多張。
  - **插入單張**：從起點往後、或從終點往前指定秒數，只插入一張。
  - **等分 Grid**：依指定欄 × 列數量在範圍內平均插入。
  - 插入的動作會排進**截圖佇列**，可以連續加入多個不重疊的擴充任務，依序背景執行；同一個時間範圍在還沒完成前會被鎖定，無法重複加入。處理中的任務可以按「取消」，已經截到的部分仍會被保留插入，不會整批作廢。

#### 2. 建立任務

在縮圖 grid 上選取兩個時間點（點一下選取、點兩下放大檢視原圖，放大檢視支援上一張／下一張導覽與底部縮圖列快速瀏覽），建立以下任一種任務：

- **剪輯**：三種切法——「時間範圍」（用選取的兩點）、「時間長度」（依固定小時數分割）、「依數量分割」（平均分成 N 段）。
- **剪輯＋合併**：多次選取範圍、加入合併清單（清單可拖曳調整順序），最後一次剪出所有片段並合併成一支影片；已加入清單範圍內的縮圖會用綠色外框標示。
- 兩種模式都可以選擇**此任務要處理的影片**：原始影片，或前面「預先處理」產生的任一支已處理影片。
- 進階選項：輸出檔名（可設定自動加上後綴，於設定頁調整）、副檔名、額外 ffmpeg 參數、合併後是否保留個別片段檔、**精確 seek**（較慢，但對時間戳異常的長時間錄影比較可靠，詳見下方「已知限制」）。

#### 3. 合併影片

跟前面「剪輯＋合併」不同，這裡是把**幾支各自獨立、完全不同的影片檔案**接成一支，跟目前載入的工作影片、縮圖選取無關：

- 選擇多支影片（可分次加入），清單可拖曳排序。
- 兩種合併方式：
  - **快速合併**：`-c copy` 直接接軌，不重新編碼，速度快，但要求所有來源影片編碼／解析度一致。
  - **相容合併**：重新編碼（h264 + aac），較慢，但來源格式不同也能合併；限制是每支來源都要有音訊軌。

---

### 二、影片處理任務

所有「剪輯」「剪輯＋合併」「合併影片」「預先處理」的任務都會排進這個佇列，依建立順序**依序**執行（不會同時跑多個），中途加入新任務會自動接續執行。

- 每個任務可以個別設定輸出位置（留空則用全域輸出資料夾，再留空則輸出到來源影片所在資料夾）。
- **清除已完成**：清掉狀態為完成／失敗／已取消的任務（「預先處理」完成的任務會保留，因為它們是「已處理影片」清單的資料來源）。
- **停止執行中的任務**：強制中斷目前正在跑的 ffmpeg 行程，需要二次確認；已停止的任務標記為「已取消」，不會被誤判成失敗。已處理的部分可能留下不完整的輸出檔案，需要自行清理。
- 每個 ffmpeg 呼叫都有逾時保護，避免遇到異常檔案時無限期卡住。

### 三、設定

- ffmpeg / ffprobe 執行檔路徑。
- 任務預設輸出檔名後綴（預設 `_edit`）。
- 截圖暫存資料夾：可直接開啟資料夾檢視、或手動清除暫存縮圖（縮圖擷取後其實會立即自動刪除暫存檔，這個按鈕主要是應付程式異常結束時的殘留檔案）。
- **通知設定**：處理結束是否發出提示音（程式即時產生的音效，不需要另外準備音檔），可調整音量、觸發時機（每個任務完成都響 / 整批任務跑完才響一次）、失敗是否用不同音效提示，並提供測試播放按鈕。只有「影片處理任務」佇列會觸發通知，縮圖擷取／擴充不會。

### 視窗置頂

頂部導覽列右側的圖釘按鈕，切換視窗是否保持在所有視窗最上層。

## 已知限制

- **極長時間、或斷線重連過的直播錄影**：來源檔案的時間戳記／索引可能不準確，導致快速 seek 定位到錯誤位置甚至讀不到內容。建議：先用「預先處理」remux 一次；剪輯任務如果還是有問題，改用「精確 seek」選項（會慢很多，但是掃描檔案本身而非依賴索引，比較可靠）。
- **相容合併模式**要求所有來源影片都要有音訊軌，純無聲影片會失敗。
- 縮圖暫存資料夾位於系統 Temp 目錄下的 `vidThumbClipper/thumbnails`，正常使用不需要手動清理。
